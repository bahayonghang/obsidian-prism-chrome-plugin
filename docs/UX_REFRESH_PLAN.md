日期：2026-11-21（America/New_York）

## 用户反馈

安装后的首版存在四个问题：不需要右下角宠物；输入区与背景缺少上游设计的光效层次；新版网页左侧导航未与主题统一；设置弹窗过长、排版简陋且动效配置不够明显。

## 本次方案

1. 完全删除宠物功能及配置入口，旧设置中的 `mascot` 字段被忽略。
2. 增加底部 Aurora 光晕、Spotlight 聚光与关闭模式；提供静态字符/网格纹理、浓度、速度以及输入框聚焦光效。
3. 为 ChatGPT 新版主导航与历史侧栏、Gemini 侧栏提供主题表面、悬停/选中态、紧凑密度和玻璃/实色/原生选项。
4. 重做紧凑弹窗和完整设置：常驻导航、保存状态、清晰分组、动效预览、中英双语与键盘操作。
5. 用包含真实结构特征的离线页面验证侧栏、输入区与首页效果；保留真实登录网站验收的独立边界。

## 实现约束

- 原生编辑器、按钮与消息节点不重建或包裹。主题通过可撤销标记作用于识别到的表面；无法识别时跳过。
- 光效层放在主区域自己的隔离层叠上下文中，位于原生文字下方，禁止接收指针事件，不覆盖侧栏。
- 字符纹理是固定装饰字符，与提示词、回复和 API Key 无关。
- 只有少量 CSS 图层持续缓慢移动，不运行永久 JavaScript 动画/轮询。动效关闭、后台标签页和系统减少动态效果时停止移动。
- 保留配置校验、跨标签更新、密钥隔离、授权后手动翻译及无网络默认行为。
- 用户截图只供分析，不提交其个人项目、会话内容或截图。
