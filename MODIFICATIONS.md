The user-provided implementation plan and two prototype browser-extension archives were used as reference material. Their completion checkboxes, performance promises and compatibility claims were not treated as verification evidence.

## Changes from the desktop suite

| Area | Modification |
|---|---|
| Distribution | Replaced CDP/Sidecar installation with Manifest V3 WebExtensions; separate Chrome service-worker and Firefox event-page manifests |
| Site adaptation | Added explicit adapters for ChatGPT and Gemini, scoped styles and reversible extension-owned UI |
| Themes | Adapted four upstream palette families, accent choices, corner styles, installed code fonts and ambient appearance |
| Settings | Redesigned compact popup/full settings, persistent navigation, motion previews, browser-local validated preferences, scene presets and sanitized import/export |
| Reading tools | Page-visible conversation outline, code folding/header enhancements and keyboard navigation |
| Motion | Aurora/Spotlight CSS layers, static decorative textures, speed/intensity controls, composer focus glow and stream highlights; hidden/reduced-motion handling; pets removed |
| Context indicator | Replaced desktop telemetry with a labeled heuristic over currently loaded visible conversation text |
| Translation | Explicit manual requests for already visible text, user-configured compatible endpoint, optional origin/data permissions and separate local credentials |
| Build and quality | Dependency-free syntax/configuration checks, isolated automated tests, deterministic allowlisted browser archives and PR/manual CI |

CDP bindings, localhost desktop daemons, local-file previews, IDE engineering controls, model effort selectors, hidden/accurate quota telemetry, desktop update machinery and artificial composer caret behavior are not included.

## v0.2.0 visual iteration

Issue #3 responds to installed-extension feedback: remove the pixel pets, restore a horizon-light visual language, identify and theme current sidebar/composer surfaces, and make motion controls easy to discover. The original reference appearance informed the palette and composition; the implementation uses lightweight browser-scoped CSS and does not copy the desktop telemetry dashboard or its WebGL/physics subsystem. Native editor and navigation ownership stays with the host websites.

## v0.2.1 regression fixes

Issues #5 and #6 address installed-browser regressions: give the toolbar popup an intrinsic size independent of its initial viewport, keep full-page options responsive, identify and clear only verified composer backdrop layers, and draw sidebar selection once per navigation item. Validation now distinguishes an actual Chromium action popup from a page with a forced viewport and adds opaque footer / nested-selection fixtures. No permissions, host access, translation behavior or remote dependencies are added.

## v0.4.3 ChatGPT thread footer band & sidebar Active Highlight

## v0.4.5 long-thread, scroll & streaming full-pipeline performance optimization

Spec #49 (#50–#54, 2026-11-26) eliminates long-thread freezes, scroll jank, streaming CPU spikes, and stylesheet/startup overhead across ChatGPT and Gemini while preserving ADR-0001/0002/0003 and zero-residue teardown: adds an offline Playwright 1×/25× regression benchmark (`tests/perf-benchmark.mjs` / `npm run test:perf -- --assert`, excluded from release packages); fixes `Formula Preview` `O(N²)` batch initialization and infinite invalid-LaTeX retry loops via `{ syncFold: false }` batching, `formulaSkipCache` negative caching, top/tail-prioritized chunked rendering (`> 12` formulas) with scoped `data-op-formula-deferred="true"` (`content-visibility: auto`), consolidated `pruneOrphanRoots()`, deduplicated geometry sync, and idempotent `setAttr`/`removeAttr`; introduces scan-scoped caching (`adapter.withScanCache`), `checkVisibility()` with boxless `display: contents` fallback, `O(N)` outermost/turn/column/code-surface/header resolution, `codeHeaderSvgCache`, three-phase read/write/geometry-separated `scan()` (updating reading width prior to dock-avoidance measurements only when changed), `ResizeObserver` initial-callback deduplication, scoped scroll-target filtering, decoupled inner-scroll dock avoidance, `O(log N)` binary-search `nearestTurn()`, and `renderedActiveTurn` rail guards; replaces `cloneNode(true)` in `textOf`/`cleanTurnText` with zero-clone live DOM traversal (`collectLiveDomText`), speeds up `estimateTokens()` via BMP `charCodeAt` ranges + surrogate-pair stepping, adds incremental `turnTokenCache`/`dirtyTurns` Context Vial and `railTurnTextCache` Conversation Rail caches, narrows `MutationObserver` into zero-allocation dirty-subsystem scheduling (`vialOnly` streaming fast path, `260 ms` stream coalescing + `streamIdle` trailing scan, `streamChoreography`-gated `characterDataOldValue`), and moves `paintHighlights()` onto 60 ms-coalesced rAF ticks reusing cached `Range` objects; splits `styles/hosts.css` into `styles/common.css`, `styles/host-chatgpt.css`, and `styles/host-gemini.css` across 4 manifest `content_scripts` groups (`all_frames: false`), replaces root `html:has(...)` with reversible `data-op-thread-overlaid="true"` and removes universal `*` key selectors, upgrades `#op-ambient-stage` to `contain: strict` with an inline SVG glyph mask tile (zero glyph DOM text nodes) and stage-scoped `data-op-aura` + `data-op-ambient-active` `will-change` gating, reuses `global.ObsidianPrismReady` in `src/content.js`, memoizes `popup/popup.js` `translateLabels()` / `checkPermission()` / boot `OP_SECRETS_STATUS`, replaces unminified `vendor/temml/temml.js` (437 KB) with pinned `temml@0.14.0` `vendor/temml/temml.min.js` (168 KB, with a 1-character `\uffff` ASCII escape patch for Chromium's MV3 `base::IsStringUTF8` loader and a permanent `assertChromeUtf8` guard in `scripts/check.mjs`), archives `docs/PERFORMANCE_PLAN.md`, and aligns package metadata and both browser manifests to `0.4.5`. No new permissions, host access, `web_accessible_resources`, bundled webfonts, or remote network dependencies are added.
